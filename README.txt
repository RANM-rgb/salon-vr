# 🥽 Salón VR Shinecon — Three.js + iPhone + DualSense PS5

Proyecto desarrollado con **Three.js** para visualizar un salón 3D inmersivo compatible con:

- 📱 iPhone / Android
- 🥽 Lentes VR Shinecon
- 🎮 DualSense PS5
- 🖥️ Navegadores modernos
- 🌐 GitHub Pages

---

# 🚀 Características

✅ Visualización 3D estereoscópica  
✅ Compatibilidad con VR móvil  
✅ Movimiento libre en el salón  
✅ Soporte para control PS5 DualSense  
✅ Controles táctiles para celular  
✅ Vista normal y modo VR  
✅ Cámara inmersiva en primera persona  
✅ Sistema responsive  
✅ Fullscreen automático  
✅ Renderizado optimizado para móviles  

---

# 🛠️ Tecnologías utilizadas

- Three.js
- JavaScript ESModules
- StereoEffect
- DeviceOrientation API
- Gamepad API
- HTML5
- CSS3
- GitHub Pages
